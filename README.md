As seis animações aprovadas do Mascarado estão ligadas às ações reais do jogo. O perfil e as perdas seguem as referências ilustradas, com dados reais, contagens inteiras e todas as 12 causas atuais visíveis. O Livro dos Mortos e os demais recursos da 0.10.3 continuam incluídos.

**Para manter o progresso, instale o APK 0.10.4 como atualização sobre a versão anterior.** O pacote `com.kauan.noitedahorda.playtest091`, o nome interno da pasta de dados e a assinatura original foram preservados. Não desinstale nem apague os dados para atualizar.

O projeto usa Godot 4.5.1, GL Compatibility. As fontes incluem PNG, áudios, fontes tipográficas, licenças, scripts, testes e ferramentas para reconstrução do APK. O cache do editor é recriado na importação. O projeto fica em `monster-game/`; as demais pastas históricas do repositório foram preservadas. Chaves de assinatura são privadas e ficam fora do repositório.
